# Compiler-Practice
My work on a compiler for a C-like language loosely based on Jack Crenshaw's 1988-1995 "Let's Build a Compiler" series. (https://compilers.iecc.com/crenshaw/)


The original tutorial uses Turbo Pascal as the implementation language and M68K assembly as the compilation target. In place of these I used Java and AMD64 (e.g. x86-64) assembly instead.
